# Bike Edge Racers 🏍️💨

An authentic first-person endless highway motorcycle racing game inspired by *Traffic Rider*.

## Features
- **First-Person Cockpit View:** 3D motorcycle handlebars, grips, mirrors, fairing, dynamic steering tilt, and camera sway.
- **Endless Highway System:** Multi-lane road with infinite road streaming and asphalt markings.
- **Dynamic AI Traffic:** Multi-lane vehicles (sedans, SUVs, trucks) moving at variable speeds.
- **Near-Miss / Close Overtake Bonus:** Passing vehicles closely at >100 km/h awards combo bonuses.
- **Cockpit Dashboard:** Analog & digital speedometer, tachometer, gear display, and distance counter.
- **Audio Engine:** Dynamic motorcycle engine pitch synthesizer, near-miss chime, and crash audio.
- **Mobile Touch & Gyro Controls:** Dedicated Gas and Brake buttons, steering buttons, and mobile tilt support.

## Android Build
The Android APK is automatically built by GitHub Actions on every push.
Download the latest `BikeEdgeRacers.apk` from the **Actions** tab under **Artifacts**.
